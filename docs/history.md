## Remaining verification and scope

Full application deployment and real-browser end-to-end checks remain unverified. A complete fresh benchmark is needed for the configured endpoint and prompt v5. Targeted tests prove validator/driver/reference behavior, not that a model follows the prompt.

Automatic product trials, general revision editing/history/export, secret rotation, explicit production-volume deletion and hostile multi-tenant hosting remain deferred. Legacy data is retained but unsupported for execution; upgrade requires stopping/draining it with the previous version. See [milestones](implementation-plan.md) and [verification/upgrade](direct-compose-verification.md).
