## Current acceptance criteria

- Authentication and session revocation apply to every protected API request and active terminal; cross-owner identifiers remain invisible.
- Generation validates one complete model response, saves identical original bytes/digest, and never starts containers. Private values stay encrypted and out of prompts/public artifacts.
- Start revalidates the saved revision and uses the same bytes. Operation admission/leases prevent conflicting actions and concurrent user deployments; unknown state retains reservations.
- Workloads share only their configuration's internal isolated bridge. No workload host publication, infrastructure/cross-configuration/host/internet access, socket mounts or unsafe Compose fields.
- Stop preserves data; ordinary Delete removes only verified stopped containers/network/artifacts and remains retryable on failure. Production volumes are retained.
- Terminal access independently checks session, ownership, applied revision and live container policy; disconnect cleanup does not stop the main service.
- Evaluator uses ten frozen tasks, independent probes, three scores out of ten, explicit failures and verified disposable cleanup. A low model score is a result; infrastructure/cleanup failure makes the run incomplete.

All nine committed migrations are required. Real Docker tests use disposable owned resources; MySQL integration never substitutes SQLite. Routine provider tests are mocked. No live requests, credential changes, deployment or legacy-data cleanup are implied by documentation or source verification.
